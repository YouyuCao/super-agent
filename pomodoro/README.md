# 番茄闹钟

一个简易的番茄闹钟：选择 10–60 分钟的专注时间，倒计时结束后显示一句随机鼓励语。

## 打开方式

用任意现代浏览器打开 `pomodoro/index.html`（双击文件，或把文件拖进浏览器窗口）。

没有构建步骤，也没有依赖：HTML、CSS 和 JavaScript 全部在同一个文件里。

## 使用方法

1. 拖动滑块选择专注时长（10–60 分钟，默认 25 分钟）。
2. 点击 **开始** 开始倒计时；再次点击可暂停，按钮会变成 **继续**。
3. 倒计时结束后，页面会显示一句随机的鼓励语，并播放一声提示音。

- **重置** 会停止倒计时，并把时间恢复到当前选择的时长。
- 倒计时进行中滑块会锁定，避免误改时长；暂停或重置后可以重新选择。
- 倒计时按真实时间计算，切到后台标签页再回来时，显示的剩余时间依然准确。
- 提示音需要浏览器允许播放声音；即使没有声音，鼓励语也会正常显示。

所有数据都只保存在当前页面里，刷新后即可重新开始。
